# Risk register and mitigation plan

| Risk | Probability / impact | Mitigation | Trigger |
|---|---|---|---|
| 3D polish hides nonfunctional circuit | High / High | Solver fixtures before art | Bulb lit without valid graph |
| LLM invents values | Medium / High | Grounding + deterministic authority | Conflicts with report |
| Scope creep | High / High | P0 gate and cutline | Unfinished mission 1 by day 6 |
| Poor tablet performance | Medium / Medium | Adaptive quality + schematic fallback | <30fps test device |
| API costs/outage | Medium / Medium | Optional backend + local hints | Missing/unavailable token |
| Child data privacy | Medium / High | No account, no PII, local only | PII appears in payload |
| Hackathon eligibility mismatch | Low / Critical | Verify region, dates, original work, .kiro | Checklist fails |
| Unlicensed visuals/music | Medium / High | Procedural assets and license inventory | Missing permission record |
| Demo recording differs from build | Medium / High | Capture live functional app | Video flow cannot reproduce |

## Anti-patterns
No huge feature backlog disguised as MVP; no fake AI chat bubble; no mocked physics displayed as science; no gratuitous spooky UI that harms educational purpose; no secret source of truth in CSS/scene state.
